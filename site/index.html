Opening on macOS

          

            
macOS blocks unsigned apps once. After downloading:

            
    
              
  1. Open Captura, then click Done on the warning.
    2. 
              
  2. Open System Settings, go to Privacy & Security, scroll to Security and click Open Anyway.
    3. 
            

            
Or run this once in Terminal:

            xattr -dr com.apple.quarantine /Applications/Captura.app
          

        


        

          
          
Opening on Windows

          

            
SmartScreen warns once for unsigned installers:

            
    
              
  1. Run the installer. If you see “Windows protected your PC”, click More info.
    2. 
              
  2. Click Run anyway to continue.
    3. 
            

            These warnings appear because the app is open source and unsigned, not because anything is wrong. Every download lists a SHA-256 checksum you can verify.
          

        


        

          
          
macOS permissions

          

            
Grant one permission under System Settings, Privacy & Security: Screen Recording, required to capture pixels. It is prompted on first capture.

            That is the only permission Captura needs. The global hotkey uses macOS’s built-in shortcut registration, so it needs no Input Monitoring or Accessibility and keeps working even when another app has Secure Keyboard Entry on. The Permissions window in the tray menu shows the grant state.
